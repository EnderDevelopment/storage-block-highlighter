# StorageBlockHighlighter

StorageBlockHighlighter is a Minecraft mod that highlights storage blocks like chests, barrels, and shulker boxes when they contain items. The highlight color is configurable, allowing players to customize the appearance of the highlighted blocks.

## Install

1. Download the mod from the [GitHub repository](https://github.com/EnderDevelopment/storagehighlighter).
2. Place the downloaded `.jar` file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft with the Fabric loader installed.

## Use

1. Play the game and look at a storage block.
2. If the storage block contains items, it will be highlighted with the configured color.
3. Press the `H` key to open the configuration screen.
4. In the configuration screen, enter the desired hexadecimal color code (e.g., `FF00FF` for magenta).
5. Click the save button to apply the new color.
